# 💰 Money Result

เว็บแอปบันทึกยอดเงินการเล่นรายวัน (zero-sum) — คำนวณ Buy In, สรุปยอดสุทธิ,
ช่วยเกลี่ยยอดให้ลงตัวที่ 0 และมีหน้า Dashboard สรุปสถิติพร้อมจัดการรายชื่อผู้เล่น

ใช้ **Google Sheets เป็นฐานข้อมูล** ผ่าน **Google Apps Script** เป็น API
และ deploy เป็น static site บน **GitHub Pages**

## 🧪 ลองใช้ก่อนได้เลย (ไม่ต้องตั้งค่าอะไร)

เปิดไฟล์ผ่าน local server แล้วต่อท้าย URL ด้วย `?demo=1` จะได้ข้อมูลจำลอง 24 วง

cd "Money Result"
python -m http.server 8777

## 🔧 ขั้นตอนที่ 1 — ตั้งค่า Google Sheets + Apps Script

### 1.1 สร้าง Spreadsheet

1. เปิด <https://sheets.new> สร้างไฟล์ใหม่
2. ตั้งชื่อไฟล์ เช่น `Money Result DB`

> **ไม่ต้องสร้างชีตหรือหัวตารางเอง** — สคริปต์จะสร้างให้อัตโนมัติในขั้นตอนถัดไป

### 1.2 วางโค้ด Backend

1. ในไฟล์ Sheet นั้น เลือกเมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมใน `Code.gs` ทิ้งทั้งหมด
3. คัดลอกเนื้อหาจากไฟล์ **`gas/Code.gs`** ในโปรเจกต์นี้มาวางแทน
4. กด **บันทึก** (ไอคอนแผ่นดิสก์ หรือ `Ctrl+S`)

### 1.3 รันฟังก์ชันติดตั้ง

1. ที่แถบด้านบนของ Apps Script เลือกฟังก์ชัน **`setup`** จาก dropdown
2. กด **Run**
3. ครั้งแรกจะขึ้นขออนุญาต ให้กดตามลำดับ:
   - **Review permissions** → เลือกบัญชี Google ของคุณ
   - หน้าจอขึ้นว่า *"Google hasn't verified this app"* → กด **Advanced**
   - → กด **Go to (ชื่อโปรเจกต์) (unsafe)** *(ปลอดภัย เพราะเป็นสคริปต์ของคุณเอง)*
   - → กด **Allow**
4. กลับไปดูที่ Spreadsheet จะเห็นชีตใหม่ 2 ชีตถูกสร้างขึ้น:

**ชีต `Players`**

| ID | Name | Active | CreatedAt |
|----|------|--------|-----------|

**ชีต `Records`**

| SessionID | Date | Player | BuyIn | Rebuy | TotalBuyIn | CashOut | Adjust | Net | CreatedAt |
|-----------|------|--------|-------|-------|------------|---------|--------|-----|-----------|

### 1.4 Deploy เป็น Web App

1. มุมขวาบนของ Apps Script กด **Deploy → New deployment**
2. กดไอคอนเฟือง ⚙️ ข้าง *Select type* → เลือก **Web app**
3. ตั้งค่าดังนี้ (**สำคัญมาก**):

   | ช่อง | ค่าที่ต้องเลือก |
   |------|----------------|
   | Description | อะไรก็ได้ เช่น `v1` |
   | **Execute as** | **Me (อีเมลของคุณ)** |
   | **Who has access** | **Anyone** |

   > ต้องเป็น **Anyone** เท่านั้น ถ้าเลือก *Anyone with Google account* เว็บจะเรียก API ไม่ได้

4. กด **Deploy** → คัดลอก **Web app URL** เก็บไว้

   หน้าตาประมาณนี้:
   ```
   https://script.google.com/macros/s/AKfycbxxxxxxxxxxxxxxxxxxxxxxxxxx/exec
   ```

> ⚠️ **ทุกครั้งที่แก้ `Code.gs`** ต้อง **Deploy → Manage deployments → ✏️ แก้ไข →
> Version: New version → Deploy** ไม่งั้นเว็บจะยังเรียกโค้ดเวอร์ชันเก่าอยู่

### 1.5 ใส่ URL ลงในเว็บ

เลือกวิธีใดวิธีหนึ่ง:

**วิธีที่ 1 — ใส่ในโค้ด (แนะนำ ถ้าใช้หลายเครื่อง)**

แก้ไฟล์ `js/config.js`:

```js
window.APP_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/AKfycbxxxx.../exec',
  ...
};
```

**วิธีที่ 2 — ใส่ผ่านหน้าเว็บ**

เปิดเว็บ → กดปุ่ม **⚙️** มุมขวาบน → วาง URL → กด **ทดสอบการเชื่อมต่อ** → **บันทึก**
(ค่าจะถูกเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น)

### 1.6 เพิ่มรายชื่อผู้เล่น

เข้าหน้า **สรุปผล → จัดการผู้เล่น** → พิมพ์ชื่อ → กด **เพิ่ม**
รายชื่อจะไปโผล่ที่หน้าบันทึกยอดทันที

## 🚀 ขั้นตอนที่ 2 — Deploy ขึ้น GitHub Pages

### 2.1 สร้าง Repository และ push

```bash
cd "Money Result"

git init
git add .
git commit -m "Money Result — daily ledger web app"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/money-result.git
git push -u origin main
```

> ถ้ายังไม่มี repo บน GitHub ให้สร้างที่ <https://github.com/new> (ตั้งเป็น Public
> หรือ Private ก็ได้ — Private ต้องใช้ GitHub Pro ถึงจะเปิด Pages ได้)

### 2.2 เปิด GitHub Pages

1. เข้า repo บน GitHub → แท็บ **Settings**
2. เมนูซ้าย → **Pages**
3. ตั้งค่า:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / โฟลเดอร์ `/ (root)`
4. กด **Save**
5. รอ 1–2 นาที แล้วรีเฟรชหน้า จะได้ลิงก์:

   ```
   https://<ชื่อผู้ใช้>.github.io/money-result/
   ```

### 2.3 อัปเดตเว็บครั้งถัดไป

```bash
git add .
git commit -m "อัปเดต ..."
git push
```

GitHub Pages จะ build ใหม่เองภายในไม่กี่สิบวินาที

## 📖 วิธีใช้งาน

### หน้า 1 — บันทึกยอดประจำวัน

1. **เลือกวันที่** (ค่าเริ่มต้นคือวันนี้) และใส่ **Buy In เริ่มต้น** ที่ทุกคนลงเท่ากัน
2. **เลือกผู้เข้าร่วม** โดยกดที่ชื่อ (กดซ้ำเพื่อเอาออก)
3. **เติมเงินระหว่างเกม** — ในการ์ดของแต่ละคน กดปุ่ม `+100` / `+200` / `+500`
   ถ้าจะเติมหลายครั้งพร้อมกัน ให้กดปุ่ม `−` / `+` ปรับจำนวนครั้งก่อน
   (เช่น ปรับเป็น `2` แล้วกด `+100` = เติม 200) หรือใช้ช่อง **จำนวนอื่น** ใส่เอง
   ทุกรายการที่เติมจะขึ้นเป็นป้ายให้กด `×` ลบได้ และจำนวนครั้งจะรีเซ็ตกลับเป็น 1 ทุกครั้ง
4. **ใส่เงินคงเหลือท้ายสุด** ของแต่ละคน — ยอดสุทธิจะคำนวณให้ทันที
5. **เกลี่ยยอด** — ถ้ายอดรวมยังไม่เป็น 0 แผงเกลี่ยยอดจะเด้งขึ้นมาเอง:
   - แตะที่ชื่อเพื่อเลือกคนที่จะนำมาเฉลี่ย
   - กด **เกลี่ยให้คนที่เลือก** ระบบจะแบ่งเท่า ๆ กัน เศษปัดไปคนแรก ๆ
   - แก้ตัวเลขในช่องไหนก็ได้เอง ขอแค่ผลรวมกลับมาเป็น 0
   - จะใส่ค่าติดลบให้กดปุ่ม **±** ข้างช่องนั้น
     (คีย์แพดตัวเลขของ iPhone ไม่มีปุ่มลบ จึงต้องใช้ปุ่มนี้แทน)
6. กด **บันทึก** (ปุ่มจะกดได้ก็ต่อเมื่อยอดรวมเป็น 0 เท่านั้น)

> 📌 บันทึกซ้ำวันเดิม = **เขียนทับ** ข้อมูลเดิมของวันนั้น (ระบบจะเตือนก่อน)
> และข้อมูลที่กรอกค้างไว้จะถูกเก็บอัตโนมัติ ปิดหน้าไปแล้วกลับมากรอกต่อได้

### หน้า 2 — สรุปผล

- **ช่วงเวลา** — กดเลือกได้หลายเดือนพร้อมกัน หรือใช้ปุ่ม *ทั้งหมด* / *3 เดือน*
- **กราฟ + ตาราง** — ยอดสุทธิสะสมรายคน เรียงจากมากไปน้อย
  แตะที่แถบในกราฟเพื่อดูรายละเอียด (แตะซ้ำเพื่อปิด)
  ตัวเลขบนกราฟจะย่อเมื่อยอดถึงหลักหมื่น (เช่น `+12.3K`) — ดูค่าเต็มได้ที่ตารางสรุป
- **ประวัติรายวัน** — กด ✎ เพื่อเปิดวันนั้นขึ้นมาแก้ไข หรือ 🗑 เพื่อลบทั้งวง
- **จัดการผู้เล่น** — เพิ่ม / แก้ชื่อ (กด ✎) / เอาออก (กด 🗑)
  การเอาออกเป็นการซ่อนจากรายชื่อ **ประวัติการเล่นเดิมยังอยู่ครบ**

## 🧮 กฎการเกลี่ยยอด

ยอดสุทธิของแต่ละคนคำนวณจาก

```
ยอดสุทธิ = เงินคงเหลือท้ายสุด − (Buy In เริ่มต้น + เงินที่เติมระหว่างเกม) + ค่าเกลี่ย
```

บันทึกได้ก็ต่อเมื่อ **ผลรวมยอดสุทธิของทุกคน = 0**

เวลากดเกลี่ย ระบบจะกระจายส่วนต่างตามกฎนี้:

- ยอดรวมเป็น **บวก (+)** → **หักเงิน** คนที่ถูกเลือกออก
- ยอดรวมเป็น **ลบ (−)** → **เพิ่มเงิน** ให้คนที่ถูกเลือก
- แบ่งเท่า ๆ กันก่อน ถ้าหารไม่ลงตัวให้ **ปัดเศษไปที่คนแรก ๆ ตามลำดับ**

ตัวอย่าง — ยอดรวมเป็น `+20` เลือกเกลี่ย 3 คน:

| คน | ค่าที่โดนหัก |
|----|------------|
| คนที่ 1 | −7 |
| คนที่ 2 | −7 |
| คนที่ 3 | −6 |

ลำดับ "คนแรก ๆ" คือลำดับเดียวกับที่แสดงในหน้าจอ (เรียงตามรายชื่อหลัก)
ไม่ขึ้นกับว่ากดเลือกใครก่อน — ผลลัพธ์จึงคาดเดาได้เสมอ

## 🔒 หมายเหตุเรื่องความปลอดภัย

Web App ที่ตั้งเป็น *Anyone* หมายความว่า **ใครที่รู้ URL ก็เรียก API ได้**
สำหรับใช้กันในกลุ่มเพื่อนถือว่าเพียงพอ แต่ถ้าต้องการกันเพิ่ม แนะนำ:

- เพิ่มการตรวจ token ง่าย ๆ ใน `dispatch_()` ของ `Code.gs`
  แล้วส่ง `token` ไปพร้อมทุก request จากฝั่ง `api.js`
- อย่าใส่ข้อมูลที่เป็นความลับจริงจังลงในชีตนี้
